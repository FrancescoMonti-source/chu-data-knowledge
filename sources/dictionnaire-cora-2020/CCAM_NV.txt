==== CCAM_NV ====
Table de la Nomenclature CCAM (contenant aussi les menus hiérarchiques de la nomenclature)
                                                     Lien sur R_ACTE.COD_ACTE :
       1   CODE                        char(7)
                                                     Code Acte CCAM
       2   LIBELLE_COURT               char(70)      Libellé raccourci de l'acte. (copie de R_ACTE.NOM_COURT)
                                                     Découpage du code acte :
       3   ORGANE                      char(1)
                                                     le 1er caractère se référe à l'organe lié à l'acte
                                                     Découpage du code acte :
                                                     les 2 premiers caractères se référe au site lié à l'acte. Il inclut donc le code
       4   SITE                        char(2)
                                                     ORGANE.
                                                     La nomenclature des sites est donnée dans CCAM_SITE
                                                     Découpage du code acte :
       5   ACTION                      char(1)       le 3ème caractère se référe à l'action lié à l'acte
                                                     La nomenclature des sites est donnée dans CCAM_ACTION
                                                     Découpage du code acte :
       6   ACCES                       char(1)       le 4ème caractère se référe au mode d'accès lié à l'acte
                                                     La nomenclature des sites est donnée dans CCAM_MODE_ACCES
       7   DT_FIN                      datetime      Date de fin d'effet de l'acte
                                                     Code (ou clé) significatif de chaque enregistrement.
                                                     - Pour 1 acte le code signifiant est CODE (Code de l'acte)
       8   CLE                         char(7)
                                                     - Pour 1 menu le code signifiant est le MENU_CODE.
                                                     Cette zone contient l'une des 2 valeurs
                                                     - 'A' : Acte
       9   TYPE                        char(1)
                                                     - 'M' : Menu
      10   ACTIF                       char(1)       Acte effectif ou non
                                           Dernière Date Modif de l'acte. Permet de pointer directement sur 1
    11   DT_MODIF              datetime    enregistrement de R_ACTE (la clé de cette table est COD_ACTE -

    13   LIBELLE_SS_ACC        char(600)

    20   HIERARCHIE            char(60)    chapitre, paragraphe, sous paragraphe
