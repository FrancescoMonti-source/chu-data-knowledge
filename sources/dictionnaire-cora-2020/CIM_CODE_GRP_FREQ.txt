==== CIM_CODE_GRP_FREQ ====
Table contenant l'utilisation des diags par Groupe utilisateur ('Diags Fréquent' d'un groupe utilisateur)
                                                        Clé - Lien sur CIM_HIERARCHIE.CODEFILS :
       1   CLE                           char(16)
                                                        Code du diagnostic
                                                        Clé - Lien Util_lib_groupe.id_groupe :
       2   ID_GRP                        int(10)
                                                        Lien sur le groupe utilisateur
       3   NB                            int(10)        Nombre d'utilisation du diag concerné
