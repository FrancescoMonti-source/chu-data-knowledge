==== CCAM_DETAIL_FAVORI ====
Table contenant les actes CCAM d'un Favori
                                                      Clé - Lien sur CCAM_FOLDER_FAVORI.ID_FOLDER :
       1   ID_FOLDER                  int(10)
                                                      Identifiant du Favori
                                                      Clé - Lien sur CCAM_NV.CODE (ou CLE) :
       2   CLE                        char(7)
                                                      Code de l'acte CCAM
       3   ORDRE_ACTE                 smallint(5)     Ordre d'affichage de l'acte dans le Favori
