==== CCAM_CODE_UTIL_FREQ ====
Table contenant l'utilisation des actes CCAM par Utilisateur ('Actes Fréquent' de l'utilisateur)
                                                        Clé - Lien sur CCAM_NV.CODE (ou CLE) :
       1    CLE                          char(7)
                                                        Code de l'acte CCAM
                                                        Clé - Lien Util.id_util :
       2    ID_UTIL                      int(10)
                                                        Lien sur l'utilisateur.
       3    NB                           int(10)        Nombre d'utilisation de l'acte concerné
