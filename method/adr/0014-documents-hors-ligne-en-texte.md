# 0014 — Document hors ligne : en texte quand c'est fidèle, sinon l'original

Statut : accepté, 2026-10-12 (Francesco).

## Décision

Un document hors ligne qui peut être partagé entre dans sources/ en texte quand la conversion garde tout ce qui compte, sinon dans son format d'origine.

## Raisons

- Le contrôle lit les fichiers texte, pas les PDF ni les pages HTML.
- Un agent cherche plus facilement dans un texte.
- Un schéma ou une copie d'écran ne passe pas en texte : là, l'original garde ce qui compte.

## Alternatives

- Toujours en texte : on perd les images.
- Toujours l'original, comme avant : le contrôle ne le lit pas.
