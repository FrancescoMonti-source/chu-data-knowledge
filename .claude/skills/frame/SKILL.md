# frame

frame est une conversation : rien ne s'écrit dans le dépôt.

1. **Affiner la question** avec la personne : le but (et, pour une question sur une base, ce que la réponse permettra de faire avec les données : retrouver, classer, joindre, compter), la population, la période, l'unité d'analyse (séjour, patient, acte), la mesure, la comparaison. Proposer une formulation, la faire corriger.
   Fini quand : la question tient en une phrase, les six points sont écrits (« sans objet » quand un point ne s'applique pas : une définition n'a ni mesure ni comparaison), et la personne les a confirmés.

Ensuite : research.
